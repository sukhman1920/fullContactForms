# AutoRadar M4

Aplicación web desarrollada con React para registrar y gestionar vehículos deportivos mediante un formulario y una API REST local.

Uso de IA

Durante el desarrollo del proyecto he utilizado ChatGPT como herramienta de apoyo.

Qué he delegado:

- Ayuda para organizar la web con React.
- Propuestas iniciales de código para el formulario con React Hook Form.
- Ayuda para las validaciones con Zod.
- Ayuda para las peticiones HTTP con TanStack Query y JSON Server.
- Ayuda para buscar y solucionar errores.

Prompts utilizados:

- Ayudame a crear una aplicación React para registrar y gestionar coches utilizando react hook form, zod y tanstack.
- Explícame cómo conectar zod con react hook mediante zodResolver.
- Ayudame con implementar las consultas y mutaciones con tanstack para registrar, editar y eliminar coches.
- Explícame cómo validar las respuestas de una API utilizando zod y safeParse.

Verificación: He probado la aplicación en el navegador utilizando Vite y JSON Server. He comprobado las funcionalidades principales, como el registro, la edición, la eliminación de vehículos y la validación de los formularios.

Trabajo realizado personalmente: He creado el repositorio, configurado el proyecto con Vite, preparado la base de datos con JSON Server, creado la estructura de archivos e integrado los componentes y las distintas tecnologías utilizadas.

He utilizado la IA como herramienta de apoyo, pero he revisado e integrado el código generado en el proyecto.

## Autopsia del proyecto

Durante el desarrollo he trabajado con tecnologías que no había utilizado anteriormente en profundidad.

Una de las principales dificultades ha sido comprender cómo se conectan React Hook Form y Zod para validar los formularios.

También he aprendido a utilizar TanStack Query para gestionar las peticiones HTTP, controlar los estados de carga y error y actualizar los datos después de realizar cambios.

Otro aprendizaje importante ha sido utilizar JSON Server como una API REST local para trabajar con datos sin necesidad de desarrollar un backend propio.

El proyecto me ha permitido entender mejor cómo se conectan los formularios, la validación de datos y las peticiones HTTP dentro de una aplicación React.
